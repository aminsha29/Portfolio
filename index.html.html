Selected work

Collateral Cover Monitor

Real-time LTV monitoring for warehouse-receipt and commodity-backed loans — computed live as outstanding ÷ (verified stock × live mandi price) against a 75% cap, with stock variance tracked as an independent risk signal. Breaches move through a priority ladder (Monitoring → Under Review → Escalated) with cure amounts calculated automatically. Directly maps to loan-against-stock and agri/SME working capital lending, replacing periodic manual audits with continuous, priced-in cover monitoring.

Built with: Prompted end-to-end in Lovable — UI, LTV/cure logic, and the escalation state machine.

LoanOS — Origination Journey & Dashboard

Two linked builds covering both sides of a Loan Origination System. The borrower journey takes an applicant from mobile OTP through bureau pull, eligibility, eKYC (Aadhaar OTP, DigiLocker selfie match), Key Fact Statement consent, e-sign, and e-mandate setup to disbursal. The ops dashboard gives credit teams a stage-gated pipeline view, funnel analytics with TAT and drop-off tracking, and live MIS reporting — mirroring the LOS/LMS split behind real personal and education loan products.

Built with: Generated as Claude Code artifacts — both flows built and iterated conversationally.

Loan Guru AI — GenAI Servicing Assistant

A borrower servicing assistant built on intent rules and TF-IDF retrieval rather than an LLM call on every message — deterministic and 100% precise on the ~12 scoped FAQs, with a confidence floor that defaults to human handoff instead of guessing. An optional Claude-generation layer exists for open-ended phrasing but isn't the default. Encodes the real architecture call a lending fintech's servicing function has to make: where GenAI adds value versus where retrieval is faster, cheaper and safer. Validated on a 30-question eval set: 100% handoff accuracy, 100% retrieval hit-rate@5.

Built with: Architecture, retrieval pipeline, handoff policy and eval harness built in a Claude Code session; optional generation path calls the Claude API directly.
